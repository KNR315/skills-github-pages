# Spin Diesel Recovery - Movement & Rest Lab

A creative educational demo for self-directed movement, rest, and atmosphere.

[Open the Movement & Rest Lab](https://knr315.github.io/skills-github-pages/spin-diesel-recovery/)

This version offers no practitioner-provided touch, treatment, product application, or appointments. It preserves the artwork, interactive map, multi-select atmosphere, fragrance matrix, local preview, and JSON download.

## Privacy

No contact, scheduling, health-history, or emergency-contact fields. No submission endpoint, email function, browser storage, analytics, remote fonts, or third-party scripts. A Content Security Policy blocks network connections and form actions. GitHub hosting still receives standard connection data. Downloads remain on the user's device. Clear my plan resets fields, map, scents, memory, and rendered review. Historical records and earlier cached copies are unaffected.

## Development

Run `node --test spin-diesel-recovery/tests/intake.test.cjs` from the repository root. Pushes to main publish with GitHub Pages.

`intake-core.js` owns schema v5, validation, educational outlines, and export data. `app.js` handles interface controls. `education.css` adds local styling; original artwork and prior styling remain. Earlier service copy is retained in Git history, not presented as a current offer.
